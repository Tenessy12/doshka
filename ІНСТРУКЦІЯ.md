# Дошка — встановлення з Google Диском і на Android-планшет

Застосунок складається з кількох файлів. Їх треба один раз викласти на безкоштовний хостинг GitHub Pages, отримати ключ доступу до Google Диска і встановити на планшет. Загалом це займає 15–20 хвилин.

**Як це працює:** дошки завжди зберігаються на самому пристрої і працюють без інтернету. Коли є мережа, застосунок сам синхронізує їх із папкою **«Дошки»** на вашому Google Диску. Тому ті самі дошки будуть і на планшеті, і на компʼютері.

Файли в архіві:

| Файл | Що це |
|---|---|
| `index.html` | Сам застосунок |
| `config.js` | Сюди вставляється ключ Google (Client ID) |
| `manifest.webmanifest`, `sw.js`, `icons/` | Щоб застосунок встановлювався на планшет і працював без інтернету |

---

## Крок 1. Викласти застосунок на GitHub Pages

1. Зареєструйтеся на **https://github.com** (якщо ще немає акаунта).
2. Натисніть **+** угорі праворуч → **New repository**.
   - Repository name: `doshka`
   - Виберіть **Public** (безкоштовний GitHub Pages працює лише з публічними репозиторіями; там лежить тільки код програми, ваші дошки туди не потрапляють).
   - Натисніть **Create repository**.
3. На сторінці нового репозиторію натисніть **uploading an existing file** (або **Add file → Upload files**).
4. Перетягніть у вікно **всі файли й папку `icons`** із розпакованого архіву. Натисніть **Commit changes**.
5. Відкрийте **Settings → Pages**. У розділі **Build and deployment**:
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)** → **Save**.
6. Зачекайте 1–2 хвилини й оновіть сторінку. Зʼявиться адреса виду
   **`https://ВАШ-ЛОГІН.github.io/doshka/`** — це адреса вашого застосунку. Запишіть її.

## Крок 2. Створити проєкт у Google Cloud і ввімкнути Google Drive API

1. Відкрийте **https://console.cloud.google.com** і увійдіть тим Google-акаунтом, на Диску якого мають зберігатися дошки.
2. Угорі натисніть вибір проєкту → **New project** → назва `Doshka` → **Create**. Переконайтеся, що вибрано саме цей проєкт.
3. Меню ☰ → **APIs & Services → Library** → знайдіть **Google Drive API** → **Enable**.

## Крок 3. Налаштувати вхід і отримати Client ID

1. Меню ☰ → **APIs & Services → OAuth consent screen** (у новому інтерфейсі розділ називається **Google Auth Platform**). Натисніть **Get started**:
   - App name: `Дошка`, User support email: ваша пошта → **Next**
   - Audience: **External** → **Next**
   - Contact information: ваша пошта → **Next** → погодьтеся з умовами → **Create**.
2. Розділ **Audience** → **Test users** → **Add users** → впишіть свою пошту Gmail → **Save**.
   Застосунок лишається в режимі «тестування» — так і має бути: увійти зможуть лише додані вами акаунти.
3. Розділ **Clients** (або **Credentials → Create credentials → OAuth client ID**):
   - Application type: **Web application**
   - Name: `Дошка`
   - **Authorized JavaScript origins** → **Add URI** → `https://ВАШ-ЛОГІН.github.io`
     (саме так: без `/doshka`, без косої риски в кінці).
   - **Create**.
4. Скопіюйте **Client ID** — довгий рядок, що закінчується на `.apps.googleusercontent.com`.

## Крок 4. Вставити Client ID у застосунок

На GitHub відкрийте репозиторій `doshka` → файл **`config.js`** → значок олівця ✏️ (Edit). Вставте Client ID між лапками:

```js
window.BOARD_CONFIG = {
  GOOGLE_CLIENT_ID: '1234567890-abc...apps.googleusercontent.com'
};
```

Натисніть **Commit changes**. За хвилину-дві сайт оновиться.

> Інший спосіб: у самому застосунку меню ☰ → **Client ID** → вставити. Але тоді це доведеться робити окремо на кожному пристрої, тож через `config.js` зручніше.

## Крок 5. Перевірити на компʼютері

1. Відкрийте `https://ВАШ-ЛОГІН.github.io/doshka/` у Chrome.
2. Натисніть угорі кнопку **«Підключити Диск»** → виберіть акаунт.
3. Зʼявиться попередження **«Google hasn't verified this app»** — це нормально для особистого застосунку. Натисніть **Continue** (Продовжити).
4. Дозвольте доступ до Google Диска (якщо є галочка — поставте її) → **Continue**.
5. Кнопка має показати **«На Диску»**. Змініть щось на дошці — за кілька секунд на Google Диску зʼявиться папка **«Дошки»** з файлом дошки.

Застосунок бачить **лише** файли, які створив сам. Решта вашого Диска йому недоступна.

## Крок 6. Встановити на Android-планшет

1. На планшеті відкрийте **Chrome** і перейдіть на `https://ВАШ-ЛОГІН.github.io/doshka/`.
2. Натисніть **⋮** (меню Chrome) → **Встановити застосунок** (або **Додати на головний екран → Встановити**).
3. На головному екрані зʼявиться іконка **«Дошка»**. Відкривайте застосунок з неї — він працює на весь екран, як звичайна програма.
4. У застосунку натисніть **«Підключити Диск»** і увійдіть тим самим Google-акаунтом. Усі дошки з Диска завантажаться автоматично.

### Керування на планшеті

| Жест | Дія |
|---|---|
| Два пальці | Масштаб і рух полотна |
| Один палець по порожньому місцю | Рух полотна |
| Утримати палець на порожньому місці, потім тягнути | Виділити кілька обʼєктів рамкою |
| Подвійний дотик | Новий стікер / редагувати текст |
| Дотик до обʼєкта | Виділити; зверху зʼявиться панель: колір, шрифт, копія, видалення |

## Що варто знати

- **Без інтернету** все працює як завжди: зміни зберігаються на пристрої (кнопка вгорі показує «Офлайн») і самі відправляться на Диск, коли зʼявиться мережа.
- **«Увійти в Google».** Google дає таким застосункам доступ на 1 годину. Коли час мине, кнопка вгорі покаже «Увійти в Google» — просто натисніть її, повторно нічого підтверджувати не треба. Зміни за цей час не губляться.
- **Якщо одну й ту саму дошку змінили на двох пристроях одночасно** (наприклад, планшет був без інтернету), нічого не втрачається: інша версія зберігається поруч окремою дошкою з позначкою «інша версія».
- **Видалена дошка** потрапляє в кошик Google Диска, звідки її можна відновити.
- **Перенести дошки зі старої версії** (`doshka.html`): відкрийте старий файл → меню ☰ → «Резервна копія (JSON)», потім у новому застосунку → меню ☰ → «Імпорт з JSON».
- **Оновлення застосунку:** якщо отримаєте новий `index.html`, просто завантажте його в репозиторій на GitHub із заміною (Add file → Upload files). Планшет підхопить нову версію сам при наступному запуску з інтернетом.

## Якщо щось не працює

| Що бачите | Що зробити |
|---|---|
| `Error 400: redirect_uri_mismatch` або `origin_mismatch` | У Client ID в полі **Authorized JavaScript origins** має бути точно `https://ВАШ-ЛОГІН.github.io` |
| `Error 403: access_denied` | Додайте свою пошту в **Test users** (крок 3.2) |
| «Потрібно дозволити доступ до Google Диска» | Під час входу поставте галочку біля доступу до Диска |
| «Браузер заблокував вікно входу» | Натисніть кнопку ще раз або дозвольте спливаючі вікна для сайту |
| Кнопка показує «Помилка Диска» | Перевірте, що Google Drive API увімкнено (крок 2.3), і натисніть кнопку, щоб спробувати ще раз |
| Немає пункту «Встановити застосунок» | Відкривайте саме в Chrome і саме за адресою `https://…github.io/doshka/` (не локальний файл) |
